# Portfolio — Karim Diakité

Portfolio personnel développé avec React 19 et Vite. Présente mon parcours, mes projets et mes compétences.

## Stack

- **React 19** + **Vite**
- **Tailwind CSS**
- **EmailJS** — formulaire de contact
- **Lucide React** + **React Icons** — icônes

## Lancer le projet

```bash
npm install
npm run dev
```

## Variables d'environnement

Créer un fichier `.env` à la racine :

```env
VITE_EMAILJS_SERVICE_ID=...
VITE_EMAILJS_TEMPLATE_ID=...
VITE_EMAILJS_PUBLIC_KEY=...
```

## Build

```bash
npm run build
```
